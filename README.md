# Probation

> Open models earn production traffic with statistical proof, and lose it when they stop deserving it.

**Status:** feasibility experiment, until Dec 6, 2026. No results yet.

Probation tests a cheaper open model on narrow decisions (classify, triage, route), lets it take only the types of decision where it proved to be reliable, keeps auditing it, and takes the work back when it degrades.

- [Experiment 01: does a certificate earned in English survive in Portuguese?](docs/experimento-01.md)
- [Plan until the gate](docs/plano-ate-06-dez.md)

The statistics are not new (testing by betting, e-processes). See "Trabalhos próximos" in the experiment.
